# Notch 1.6.2

Notch is a desktop teleprompter for Windows: a small card of script text near
your webcam that scrolls as you speak and stays out of screen captures.

1.6.2 is the release that makes it something you can keep using. Your script,
notes, card position, theme and learned speaking rhythm survive an update
instead of being reset by one; every surface shares one palette and one set of
springs; a note belongs to the card it was opened from; the reading line
separates what you are saying from what is coming; Manual mode hands the
speech model's memory back; and a packaged build leaves the log a support
conversation needs.

## Your saved work survives an update

The script, the notes, the preferences, the card's placement and the profile
that learns your speaking rhythm are stored under a schema that migrates one
version at a time, so a new build reads what the last one wrote instead of
starting over. The old file is kept as a snapshot before its first rewrite, a
corrupt store falls back to its backup, and a file from a newer build is read
for what this one understands rather than rejected. Each launch also keeps one
timestamped copy of what it found, up to the newest ten, so the previous
session stays recoverable.

## The reading line has three tiers

The words being spoken carry a brighter accent with a hairline stroke, the run
the predictor expects next sits behind them in a quieter colour, and the
resting ink is what is still to come. The stroke thickens the glyphs instead of
changing their weight, so the line never re-wraps when the state changes, and
the change crossfades over 120 ms rather than snapping.

## A note is a piece of the reader

Notes take the card's fill, border, radius and dark-mode edge catchlight, and
they open and close against the card: a note grows out of the reader and
travels to its corner, and on close it shrinks and returns. A note grabbed
mid-dismissal comes back, a drag coasts for one bounded frame, and the saved
position follows where the note settles.

## One palette, one set of springs

The colours, radii and spacing of every surface now live in one place, as do
the spring presets and crossfade durations, which ends the small drift of a
note a shade off the card it came from and of a hover that took a different
time on each surface. Switching between light and dark no longer repaints one
surface at a time: the frame on screen is captured, everything is recoloured
underneath it, and the old frame dissolves over 220 ms.

## Manual mode gives the memory back

Leaving Voice mode for Manual drops the acoustic model, which took the process
from 208 MB to 89 MB across three measured cycles with no growth. Returning to
Voice reloads it in 3.0–4.2 seconds behind the existing status line.

## A build you can support

Windowed builds write a rotating log beside the executable, record unhandled
exceptions from the main thread and from workers, and keep native fault traces
in a separate file; without that, a launch-day crash left nothing to read. The
reader's own words are no longer written to that log — transcript tracing is
opt-in through `NOTCH_TRACE_TRANSCRIPT=1`.

Two copies of Notch can no longer run at once. They shared one state file, one
camera and one set of global shortcuts, and the last save won; a second launch
now says the reader is already open and exits. The installer uses the same
named mutex, so an upgrade asks for the running reader to be closed instead of
replacing files underneath it.

Smaller fixes in this release: an unplugged or muted microphone clears from the
ribbon in the same wall-clock time on a busy machine as on an idle one, and a
note no longer opens with a focus ring on its close glyph instead of the text
field.

## What the eight-hour run tested

The packaged build was frozen from `c5ee8f2` at 00:55 on 2026-11-15 and ran
for 28,801 seconds against an isolated state folder, with a GUI heartbeat
required to stay under sixty seconds throughout. It passed: the process
survived, the interface kept responding, the log stopped after startup and the
fault file stayed empty.

That run measures survival and responsiveness. It is not evidence that every
feature behaved for eight hours, and the installer attached to this release is
exactly the tree it hashed. The full record — file manifest, check output and
the caveats — is in [`docs/release/1.6.2.md`](../blob/main/docs/release/1.6.2.md).

## Known limits

- **Reduced motion breaks Done in this build.** If Windows animations are
  turned off, leaving the editor does not commit the script and the editor
  stays open. The fix is on `main`; the next build carries it. Turn animations
  back on under Settings → Accessibility → Visual effects if you need to edit
  a script with this build.
- **Head tracking is experimental and off by default.** Region calibration has
  not been validated against a release, so it stays behind an explicit opt-in.
- **The build is unsigned**, as described above.
- The 28,800-second run covers process survival. A functional pass over the
  modes, the microphone and the shortcuts is recorded separately.
